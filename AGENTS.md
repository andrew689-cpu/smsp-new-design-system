# SMS Perkasa Design System

Design system for PT. Sumber Makmur Surya Perkasa, an Indonesian B2B structural-steel
distributor. Next.js + TypeScript + Tailwind v4, tokens-first.

```
npm run dev          # the app, with /showcase as the component gallery
npm run check        # tokens current, types, lint, contract, unit tests
npm run check:full   # the above plus Playwright (both themes x three viewports)
npm run tokens       # regenerate theme.css and smsp-brand-identity.md from tokens/
```

## The agent contract

Rules every agent must obey here. The design-system detail lives in the
`smsp-design-system` skill — **load it before writing any UI.** This section is the part you
must hold in mind even when you have not loaded it.

### Generated files are never edited

`tokens/` is the source of truth. These are generated by `npm run tokens`:

- `src/styles/theme.css`
- `smsp-brand-identity.md`

`npm run tokens:verify` fails if either is stale, and it runs in `check` and in pre-commit.
If a screen needs a value that does not exist, **extend `tokens/`** — never reach for a literal.
See `docs/adr/0001-tokens-are-the-source-of-truth.md`.

### Tailwind namespaces are reset, so wrong classes vanish silently

`--color-*`, `--spacing-*`, `--text-*`, `--font-*`, `--radius-*` and the rest are reset to
`initial`, so an off-system utility **does not compile**. It is not an error — it is nothing,
and the style silently disappears. `min-h-11` and `font-normal` are dead here; use
`min-h-touch` and `font-regular`. `w-10` is worse: it compiles as 128px, not 40px.

`npm run lint:contract` catches these, and the PostToolUse hook runs it on every edit.
See `docs/adr/0003-tailwind-v4-with-namespace-resets.md`.

### Four enforcement tiers

| Tier | What | How |
|---|---|---|
| **0** | Unrepresentable | `Alert`/`Badge` require icon **and** label; `Spec` requires a `unit`; `Logo` takes a variant, not a `className` |
| **1** | Blocks commit | No raw hex, no primitives in UI, no arbitrary values, weights 400/700/900 only, no raw px/ms/cubic-bezier, focus never removed, axe clean in both themes |
| **2** | Warning | Status colours outside feedback, logo below minimum size, measure outside 45–75ch, English-looking user copy |
| **3** | **Human judgement — not machine-checkable** | "red used sparingly", "whitespace reads as restraint", "*ramah* not cold", icon consistency |

Tier 3 is named deliberately. **Do not claim those pass** — say you have not verified them.
A contract that fakes a check for them teaches everyone to ignore its output.

### Precedence between the two specs

`smsp-brand-identity.md` wins on every **value**. `ui-ux-design-principles.md` advises on
**composition and layout only**; where it names a number, re-express it as a token or drop it.
See `docs/adr/0002-brand-doc-outranks-the-ux-guide.md`.

### Domain

No cart, no checkout. The single conversion action is **Hubungi Sales**. Prices are
display-only. User copy is Bahasa Indonesia, sized for 20–30% growth over English; token
names stay English. See `CONTEXT.md`.

## Known wart

Token names keep their documented spelling, so the Tailwind utility repeats the group prefix:
`bg-bg-surface`, `text-text-default`. Verbose, but it maps 1:1 onto
`smsp-brand-identity.md` and avoids inventing a second vocabulary for the same colour.
